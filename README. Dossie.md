Robô de Dossiês de Compliance & Due Diligence 🛡️
Aplicação desktop desenvolvida em Python para automação de consultas cadastrais e geração de relatórios de compliance (dossiês) por CPF, focado em due diligence, análise de risco e verificação cadastral dentro dos limites da LGPD.

🚀 Principais Funcionalidades
Interface Gráfica Intuitiva: Aplicação leve na janela própria (sem uso de terminal), desenvolvida para facilitar o uso corporativo no dia a dia.
Consultas em Bases Públicas: Validação de CPF e situação cadastral (Receita Federal), varredura de vínculos societários/QSA (CNPJ) e consulta de processos judiciais por polo e tipo (DataJud/CNJ).
Geração Automática de PDF: Compilação dos dados encontrados em um relatório gerencial limpo, estruturado e profissional.
Pronto para uso (.exe): Empacotado via PyInstaller para rodar de forma autônoma como apresentadovel autônomo, sem necessidade de configurar ambiente de programação nas máquinas clientes.
🛠️ Tecnologias Utilizadas
Python (principal da linguagem)
Tkinter (Interface gráfica desktop)
Solicitações (Integração com APIs públicas)
PyInstaller (Empacotamento do novovel)
